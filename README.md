**Scrum Bot**
/set-scrum-time: 스크럼 시간 저장. 스크럼 0, 30, 60분 전에 알림.  
/get-scrum-time: 스크럼 시간 보기.  
/create-vote: 스크럼 시간 투표 기능. 투표 종료 시각, 옵션 추가를 허용할지, 무기명 투표로 할지 선택 가능. 종료 시 득표수 내림차순으로 결과 공지, 조기 종료 가능. **채널별 처리**  

**Notice Bot**
/수강료_납부_안내: 수강료 납부 안내 페이지 가져오기
/강연_면담_안내: 날짜와 함께 적힌 강연 및 면담 페이지 가져오기
/타대생_안내: 제목에 '타대생'이 포함된 페이지 가져오기
/실습_발표_kcloud_안내: 태그가 실습 혹은 발표인 페이지 가져오기
/개강_안내: 몰입캠프가 처음인 사람들을 위한 공지사항 페이지 가져오기
